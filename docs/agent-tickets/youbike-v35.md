# YouBike v3.5 — 地圖範圍列表 + 迭代功能

Status: ready
Risk: low(單一前端改動,資料層不動)
Mode: linear

## Goal(共識決議)

1. **列表 = 地圖可見範圍內的站(上限 300)**
   - `moveend`/`zoomend`(使用者停下)+ 150ms 緩衝後,以地圖 bounds 過濾列表
   - 有搜尋關鍵字時自動停用範圍過濾(Q1)
   - 定位模式(userLoc 存在)優先:距離排序、不套範圍過濾(Q4)
   - 範圍內 ≤300 筆:全部顯示
   - 範圍內 >300 筆:排除「目前被 markercluster 聚合」的站再排序;若排除後 ≤300 就全列
     - 判斷法:marker.__parent chain 走到 zoom 以上的祖先 cluster = 被聚合
     - 選中站永遠保留,不因聚合被排除
     - 列表頂端提示「另有 N 站已聚合於地圖」(Q3-追問 B)
2. **選中站不在列表時自動插入最上方並高亮**(方案 A 兜底)
3. **範圍過濾開關**:header 加 toggle「只看此地圖範圍」,預設開啟(Q6)
4. **新功能**:
   - URL 同步地圖視野 ?lat=&lng=&z= — 分享連結直接開在同一位置(Q5-a)
   - Header 範圍統計列:「範圍內 X 站 · 共 Y 輛可借 · Z 站無車」(Q5-b)
   - 📍 二次點擊 = 回到定位處(地圖 flyTo 自己)(Q5-c)
   - 範圍內低車量徽章:「⚠️ N 個無車站」點了過濾出它們(Q7-f)

## 不做
- 臺北車型明細(TDX 匿名會 429,需註冊 key,暫緩)
- 地圖雙擊收藏(與縮放手勢衝突)
- 卡片更新時間欄位
